# Parts and Publishing

Linked parts reference authoritative source parts rather than copying an independent musical score. Part-specific layout can change without changing pitch, onset or duration.

Cue notes retain source event and part IDs and are muted in playback. Range and engraving audits identify warnings without modifying music.

Batch publishing creates deterministic score and part filenames. A transactional export stages every file and commits only when all renders succeed; failure removes staged output.
