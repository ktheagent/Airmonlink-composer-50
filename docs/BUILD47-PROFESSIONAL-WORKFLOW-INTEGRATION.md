# Build 47 — Professional Workflow Integration

Build 47 verifies Setup, Write, Engrave, Play and Publish as modes of one
authoritative score rather than separate documents.

- Mode changes retain score identity, selection, cursor/current measure,
  viewport state, parts and dirty state.
- Passage editing covers copy/paste, transpose, voice change, automatic
  beaming, notation, multi-step undo and multi-step redo.
- SATB workflow covers four parts, lyrics, slurs, dynamics, synchronized
  Tonic Sol-fa, performance scheduling, `.airscore` reopen and MusicXML.
- Ensemble workflow covers transposition, linked parts, cues, part-specific
  layout, deterministic batch export and reopen.
- Existing piano regression covers chords, tuplets, articulations, pedal,
  engraving layout and publication.

The checkpoint remains source-verified and not final.
