# Tonic Sol-fa in Build 40

Staff and Tonic Sol-fa are two views of the same score events. Editing a selected Sol-fa syllable updates the authoritative pitch; staff notation and playback immediately use that pitch.

Supported semantics include syllables, chromatic variants, octave marks, rests, dots, dashes, underscores, bars, ties, slurs, repeats and modulation according to the project convention. Lyric verses remain independent metadata attached to notes.

Use Staff, dedicated Sol-fa or split Staff + Sol-fa views. Save/reopen and publication derive from the same model. Run Sol-fa diagnostics after imported or heavily edited passages.
