# Premium Composition Hub

Open the Hub with the vertical **Compose** launcher or `Ctrl+Shift+C`.

The eight groups are Create, Harmony, Arrange, Transform, Analyse, Lyrics and Choir, Playback and Practice, and Publish. Tools are filtered by the current selection and score context.

Assisted operations use this workflow:
1. Select authoritative score events.
2. Choose a tool.
3. Enter guided values.
4. Preview without mutating the score.
5. Inspect warnings and alternatives.
6. Apply once as a single undoable transaction, or close the preview to reject it.

Generated events are marked with the tool and preview identity. Assistance is never represented as guaranteed musical correctness.
