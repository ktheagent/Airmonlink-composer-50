# Build 43 Known Limitations

Build 43 is a local source checkpoint, not a professional release.

Not yet verified or complete:

- Windows compilation, installation, startup, upgrade and uninstall;
- code signing and Windows file metadata;
- real MIDI keyboard and MIDI output devices;
- real audio devices and latency;
- physical printers and printer cancellation behaviour;
- human usability on Windows;
- cross-staff and cross-part spanners;
- nested tuplets beyond the verified single-level N:M model;
- advanced feathered beams, tremolo beams and cross-staff beams;
- complete collision avoidance for every notation combination;
- final page engraving, parts and publishing release gates.

Unverified controls remain hidden rather than presented as completed features.
